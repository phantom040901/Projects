# IT16Project — File Encryption System

A VB.NET desktop application designed to secure sensitive files through encryption. The system implements an authentication policy where only authorized personnel can decrypt submitted files, ensuring confidentiality and access control.

## Features
- File encryption using cryptographic algorithms
- Role-based access control for decryption
- User authentication system (login-based authorization)
- Secure file submission and retrieval workflow

## Tech Stack
- **Language:** VB.NET
- **Framework:** .NET 8.0 (Windows Forms)
- **Database:** SQLite
- **UI Library:** Guna UI 2
