# VapeShop — Inventory Management System

A VB.NET desktop application designed as an inventory management system for **Mad Dogz Vape Shop**, a small business located in MAA, Davao City. The system helps the shop manage product inventory, track stock levels, and streamline daily business operations.

## Features
- Product inventory tracking and management
- Stock level monitoring
- User-friendly desktop interface for shop staff

## Tech Stack
- **Language:** VB.NET
- **Framework:** .NET 8.0 (Windows Forms)
- **UI Library:** Guna UI 2
